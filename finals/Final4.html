PART 4: FILE SHARING
File Services Requirements
  1. All departments/sections should have one public folder (read/write). Domain users cannot access other department folders.
  2. A university public folder where all domain users can access (read/write)
  3. An installer folder containing applications that only the administrator can access.
  4. All folders except the computer engineering folder should contain only office documents (.ppt, .doc, .docx, .xls, .pptx, .pdf etc.)
  5. Information technology folder should contain all files except executable files.
  6. Storage quota for each folder is 1GB.
  7. Map the shared folder for each client workstation.
Step 1: Create Folders
  • Create directories from Part 2 (departments/sections)
  • Create University folder
  • Create Installer folder
  • Optional: Run a script to automate folder creation
Step 2: Configure File Services
  1. Server Manager → Roles → Add Roles → File Services
  2. Click Next → Next
  3. Check all options except Windows Server 2003 File Services
  4. DFS Namespaces: Enter Namespace Name: NameSpace1
  5. Click Next → Next
  6. In Credentials section:
    • Click Select button
    • Type domain admin username and password
  7. Click Next → Next
  8. Select local disk (C Drive)
  9. Click Next until installation completes
  10. Restart system
Step 3: Quota Management
  1. Start → Administrative Tools → File Server Resource Manager
  2. Navigate to Quota Management → Quota Templates
  3. Create New Quota Template:
    • Template Name: 1GB
    • Space Limit: 1 GB
  4. Click Add
Step 4: File Screening Management
General File Screen Template
  • Permissions: Read/Write
  • Users: All
  • Files: Only .ppt, .doc, .docx, .xls, .pptx, .pdf, etc.
  • File Template Name: General
  • File Screen Template: Check all except General
IT (Information Technology) File Screen Template
  • Permissions: Read/Write
  • Users: Information Technology department
  • File Screen Template: Check all except Executable Files
Steps to Create Templates:
  1. File Groups → Create File Group with appropriate name
  2. File Template → Create File Template with restrictions as specified above
Step 5: Provision Shares
  1. Administrative Tools → Server Manager → Roles → File Services
  2. Select Share and Storage Management
  3. Click Create Provision Share
  4. Open Shared Folder Provision Wizard
  5. Select folder location you want to share
  6. Available Volumes: Click or select C Drive
  7. Click Next → Next
  8. Check SMB (Server Message Block protocol)
  9. Click Next → Next
  10. In SMB Permission section: Add user groups with their specific permissions (see sections below)
  11. Click Next → Next → Next
  12. Apply Quota: Select the 1GB template
  13. Click Next
  14. Apply File Screen: Select appropriate template from dropdown (General or IT)
  15. Click Next → Next → Create → Close
University Share
  • SMB Share Name: University
  • Permissions: Read/Write
  • Users: All Domain Users
  • File Screen Template: General
Installer Share
  • SMB Share Name: Installer$
  • Permissions: Read/Write
  • Users: Administrator
  • File Screen Template: General
Department Shares
  • For each department/section folder from Part 2:
  • Permissions: Read/Write
  • Users: Respective department users only
  • File Screen Template:
    • General (for all departments except Computer Engineering)
    • All Files allowed (for Computer Engineering)
    • IT template (for Information Technology)
Step 6: Map Shared Folders for Client Workstations
  • On each Windows XP/Windows 7 workstation
  • Open File Explorer / My Computer
  • Right-click → Map Network Drive
  • Select drive letter (e.g., Z:, Y:)
  • Enter folder path: \\ServerName\ShareName
  • Check "Reconnect at logon"
  • Click Finish
  • Verify mapped drives appear in File Explorer
