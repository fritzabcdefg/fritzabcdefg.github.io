Notes / Description

PART 7: WEB SERVER
Requirements
  1. Create a simple university website to be hosted on IIS 7
  2. Create a simple website for each department
  3. Create subdirectories for each department in the wwwroot folder
Step 1: Install Web Server Role
  1. Open Server Manager
  2. Navigate to Roles section
  3. Click "Add Role"
  4. Select "Web Server (IIS)"
  5. Click Next and follow prompts to install
Step 2: Add Web Server Features

During Web Server (IIS) role installation, ensure the following are checked:

  • Application Development
  • IIS 6 Management Compatibility
  • FTP Server
Tool Download:

Download AnyToISO Converter from: https://anytoiso-converter.en.download.it/

Install this tool for website content management.

Step 3: Create and Configure University Website
  1. Open IIS Manager: Start → Administrative Tools → IIS Manager
  2. In IIS Manager:
    • Expand your server domain name
    • Right-click "Sites" → Select "Add Website"
  3. Configure website properties:
    • Site Name: tupt
    • Physical Path: C:\inetpub\wwwroot\tupt
      • Navigate: Computer → inetpub → wwwroot
      • Create new folder named "tupt"
      • Select this path
    • Assigned IP Address: 172.31.0.31
    • Host Name: tupt.edu.ph
  4. Click OK to create the website
Step 4: Configure Output Caching
  1. In IIS Manager, select the "tupt" website
  2. Scroll through the features list and locate "Output Caching"
  3. Right-click Output Caching → Select "Add" (or similar option)
  4. Configure cache settings:
    • File name extension: .aspx
    • User Mode Caching: Check this option
  5. Click OK to save settings
Step 5: Prepare Website Content Structure
  1. Navigate to: Local Disk → inetpub → wwwroot → tupt
  2. Copy the "iisstart" HTML file into the tupt folder
    • Note: The "iisstart" folder/file serves as the index/home page
  3. Create subdirectories for each department inside the tupt folder:
    • Create "Academics" folder
    • Create "Administrative" folder
    • Create directories for each specific department (from Part 2)
  4. Add appropriate HTML/ASP.NET content to each subdirectory
Folder Structure Example: 
wwwroot/
├── tupt/
│   ├── iisstart.htm (index/home page)
│   ├── Academics/
│   ├── Administrative/
│   ├── ComputerEngineering/
│   ├── InformationTechnology/
│   └── (other departments...)
Step 6: Access and Test Website
  1. In IIS Manager:
    • Go back to Sites section
    • Right-click the "tupt" website
    • Select "Browse" (opens Internet Explorer automatically)
  2. Test the website locally and verify pages load correctly
  3. Test website access from multiple machines:
    • Open Internet Explorer on Windows Server 2008
    • Navigate to: http://tupt.edu.ph/
    • Test on Windows 7 workstation: http://tupt.edu.ph/
    • Test on Windows XP workstation: http://tupt.edu.ph/
  4. Verify all pages load correctly and are accessible from all client machines
✓ Web Server Setup Complete

Your IIS 7 server is now:

  • Hosting the TUPT university website
  • Serving department-specific content
  • Caching .aspx pages for improved performance
  • Accessible from all client workstations
