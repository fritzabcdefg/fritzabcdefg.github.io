Task 7: GROUP POLICY MANAGEMENT
Initial Setup Steps
  1. Go to Start → Administrative Tools → Active Directory Users and Computers
  2. Create a new Organizational Unit → BSIT
  3. Add all students to the Organizational Unit
  4. Go to Start → Administrative Tools → GROUP POLICY MANAGEMENT
  5. Navigate to Domain → View the OU of Students
  6. Right-click the OU → Create a GPO in this domain → Add GPOs needed for your system
  7. After creating the GPO → Right-click the GPO → Edit, then follow the steps below for each requirement
USER CONFIGURATION POLICIES
GPO NAME: User Interface Restrictions
  • ✓ Remove links and access to Windows Update → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove links and access to Windows Update
  • ✓ Remove Network Connections from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove Network Connections from the Start Menu
  • ✓ Remove Help menu from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove Help menu from the Start Menu
  • ✓ Remove Run menu from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove Run menu from the Start Menu
  • ✓ Remove My Pictures icon from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove My Pictures icon from the Start Menu
  • ✓ Remove My Music icon from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove My Music icon from the Start Menu
  • ✓ Remove My Network Places icon from the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Remove My Network Places icon from the Start Menu
  • ✓ Add "Logoff" on the Start Menu → Enabled
    User Configuration → Policies → Administrative Templates → Start Menu and Taskbar → Add "Logoff" on the Start Menu
  • ✓ Remove Task Manager from CTRL+ALT+DEL → Enabled
    User Configuration → Policies → Administrative Templates → System → Ctrl+Alt+Del Options → Remove Task Manager
GPO NAME: Internet Explorer Settings
  • ✓ Internet Explorer Browser Title – Title Bar Text → <domain name>
    User Configuration → Policies → Windows Settings → Internet Explorer Maintenance → Browser User Interface → Browser Title
GPO NAME: Windows Update
  • ✓ Prohibit access to properties of components of a LAN connection → Enabled
    User Configuration → Policies → Administrative Templates → Network → Network Connections
  • ✓ Prevent access to the command prompt → Enabled
    User Configuration → Policies → Administrative Templates → System → Prevent access to the command prompt
  • ✓ Prevent access to registry editing tools → Enabled
    User Configuration → Policies → Administrative Templates → System → Prevent access to registry editing tools
  • ✓ Prohibit access to the Control Panel → Enabled
    User Configuration → Policies → Administrative Templates → Control Panel → Prohibit access to the Control Panel
