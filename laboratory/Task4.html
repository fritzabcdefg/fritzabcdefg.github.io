Task 4: RAID

Notes:

For Task 4, we are configuring RAID in Windows Server 2008 Hard Disks.

Task 4: RAID Installation

Requirements:
Perform the RAID Installation of the following levels:
RAID 0: Stripped Volume
RAID 1: Mirrored Volume
RAID 5
Spanned Volume

Steps:
1. Clone Windows Server 2008 that you used for your DHCP activity.
2. After cloning, click Settings → Storage → click add attachment icon → Hard Disk.
3. After opening medium selector → click Create → check pre-allocate full size → allocate 50 MB → click Finish.
4. Make sure you create 10 of these hard disks.
5. Back to Settings → Storage → add/attach all of these hard disks in your WS2008.
6. Start your WS2008.
7. Click Start → Administrative Tools → Server Manager → expand Storage → Disk Management.
8. After clicking Disk Management, you will see a tab pop out "Initialize Disk" containing all the disks you attached in your VM. Make sure MBR is the partition style.
9. Click OK to initialize the disks.

RAID 0: Stripped Volume
10. Click Disk 1 → New Stripped Volume.
11. Next → select Disk 2 → Add → Next → name volume as RAID0 or Stripped → check "Perform a quick format" → Next → Finish → Yes if prompted → wait.

RAID 1: Mirrored Volume
12. Click Disk 3 → New Mirrored Volume.
13. Next → select Disk 4 → Add → Next → name volume as RAID1 or Mirrored → check "Perform a quick format" → Next → Finish → Yes if prompted → wait.

RAID 2: Spanned Volume
14. Click Disk 5 → New Spanned Volume.
15. Next → select Disk 6 → Add → select Disk 7 → Add → Next → name volume as Spanned → check "Perform a quick format" → Next → Finish → Yes if prompted → wait.

RAID 5
16. Click Disk 8 → New Spanned Volume.
17. Next → select Disk 9 → Add → select Disk 10 → Add → Next → name volume as RAID5 → check "Perform a quick format" → Next → Finish → Yes if prompted → wait.
18. After waiting for all the volumes to be created, you can check the status of each volume in Disk Management.
